# Pulsar Fusion Web

[中文](README.md) · [English](README.en.md)

针对 **Pulsar Xlite v4 Mini** 的 Web 配置工具，支持本地运行和 GitHub Pages，使用桌面版 Chrome / Edge 连接鼠标。

## 启动与连接

打开 [在线版](https://cbingb666.github.io/pulsar-web/)，或在本地运行：

```sh
npm install
npm run dev
```

在桌面版 Chrome / Edge 打开终端打印的本地地址（默认 `http://localhost:5173`），点击 **连接鼠标**，在浏览器选择器中选择 Xlite v4；使用接收器时选择 **1K Dongle** 或 **8K Dongle**。Safari / Firefox 不支持此处需要的 WebHID。内嵌浏览器若没有设备选择器，请使用独立 Chrome / Edge。

无线配置时只需插入接收器，开启鼠标并确认能无线移动光标，无需连接鼠标数据线。若连接失败，先唤醒鼠标、关闭其他配置网页或软件，再重新插拔接收器并连接。若仍失败，可在 **连接诊断 → 导出诊断** 保存错误信息；导出内容包含浏览器版本、接口信息与配置通信记录，不记录日常键鼠输入。

配置和本地宏保存在当前浏览器，无需账号。浏览器授权与存储按站点隔离；localhost 的草稿不会自动迁移到在线站点，可通过 JSON 导入导出。

首次授权后，刷新或重新打开同一站点会自动尝试连接已授权且当前接入的支持设备，并读取配置，不弹出设备选择器。未找到设备时仍可离线编辑，连接失败时可点击 **连接鼠标** 重试。未应用的本地草稿会保留，不会自动写入鼠标。

点击 **断开** 会关闭当前浏览器在该站点的自动连接，刷新或重新打开页面后仍保持断开，直到再次手动连接并读取成功。取消选择或连接失败不会重新开启自动连接；意外掉线不改变此偏好。清除站点数据会重置偏好，清除设备授权后需重新手动授权。

## 本地部署

```sh
npm run build
npm run preview
```

生产文件位于 `dist/`，可通过 HTTPS 静态托管，无需服务端或本地驱动桥接程序。设备连接需要 HTTPS 或 localhost。

使用 GitHub Pages 时，在仓库 **Settings → Pages → Build and deployment** 中选择 **GitHub Actions**；推送到 `main` 后会自动构建和部署。当前项目站点为 `https://cbingb666.github.io/pulsar-web/`。私有仓库能否启用 Pages 取决于 GitHub 套餐，参见 [GitHub 官方要求](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages)。构建、路径检查和工作流说明见 [开发指南](docs/development.md)。

## 功能与兼容范围

- 读取设备配置；性能设置在后台自动保存，按键、电源和导入草稿等更改暂存后确认保存。
- 6 个设备配置槽位的读取、切换；本地草稿及 JSON 配置备份、导入导出。
- 1–6 档 DPI、独立 X/Y、50–32000 DPI、10 DPI 步长、当前档位及各档指示灯颜色。
- 回报率、0–15 ms 消抖、0.7/1/2 mm LOD、Motion Sync、角度捕捉、波纹控制。
- 6 个按键：鼠标、滚轮、键盘组合、DPI、配置循环、多媒体、快捷功能及设备宏；需保留至少一个左键。
- DPI 指示灯关闭、常亮、呼吸，以及亮度和呼吸速度。
- 电量、充电状态、固件版本；30 秒至 15 分钟休眠、低电量阈值。
- 宏录制、键盘/修饰键/鼠标/滚轮/延迟事件、编辑排序、JSON 和原版 Fusion CSV 导入导出。
- 设备宏上传、回读、导入、删除；按键绑定支持一次、指定次数、按住循环、再次按下停止。删除前检查全部槽位中的引用。
- 1K / 8K 接收器配对、通信日志和诊断导出。
- USB 有线固件刷写、配置恢复和出厂恢复；固件刷写与出厂恢复为实验性功能，恢复设备设置前需单独确认。

| 连接方式 | 设备标识 | 最高可选回报率 |
| --- | --- | --- |
| USB 有线 | `3710:3401` | 1000 Hz |
| 原版 1K 接收器 | `3710:5402` | 1000 Hz |
| 原版 8K 接收器 | `3710:5403` | 8000 Hz |

仅原版 8K 接收器提供 2000 / 4000 / 8000 Hz 和接收器指示灯设置。其他型号及 Gen.2 接收器不在支持范围内。8K 高回报率、灯光和异常恢复仍有兼容限制，使用前请阅读下方 [限制与风险](#限制与风险)。

## 1K / 8K 接收器配对

顶部 **配对接收器** 可在未连接鼠标时打开，仅适用于原版 1K / 8K 接收器与 Xlite v4，不用于固件更新。

1. 只插入目标 1K 或 8K 接收器，拔下其他接收器和鼠标 USB 线，开启鼠标无线模式。
2. 同时按住鼠标左键、右键和滚轮中键 3–5 秒，直到 LED 闪烁。
3. 点击 **选择接收器并开始配对**，在浏览器选择 **1K Dongle** 或 **8K Dongle**，最多等待 30 秒。
4. 配对后网页会读取鼠标配置；本地未应用草稿保留。若未完成配置连接，关闭窗口后点击 **连接鼠标**，选择刚配对的接收器。
5. 在性能设置中调整回报率；8K 接收器还可在电源管理中调整接收器灯光。

配对会改变原有无线连接关系。**取消** 只停止本页等待；已发送的配对命令不能撤回，取消或超时后应重新连接检查状态。配对不会在页面加载或自动连接时触发。连接或配对失败时，可通过 **连接诊断 → 导出诊断** 保存排障信息。

## USB 有线固件刷写

这是实验性功能。入口在 **电源管理 → 固件 → 刷写鼠标固件**，仅针对 Xlite v4 Mini 鼠标本体 `3710:3401`，不刷写接收器。当前只接受官方 **XS1 1.0.1.7** 固件；更高版本的鼠标不能通过此流程降级。

1. 从 [Pulsar 官方下载页](https://www.pulsar.gg/pages/download) 的 Xlite v4 Mini 区域下载 `Pulsar_Firmware_XS1_v1017_v125_T01.zip`，解压得到 `Pulsar_Updater_v1017_v125_T01.exe`。
2. 只连接目标鼠标的 USB 数据线，拔下其他 Pulsar 鼠标与接收器。刷写前请导出需要保留的配置和宏。
3. 在弹窗中选择该 `.exe`。网页仅提取并校验其中的鼠标固件，不运行 Windows 程序。也可导入内容完全相同的原始 `.bin`；不接受 ZIP、其他型号或未知版本。
4. 确认目标设备后点击 **选择鼠标并进入升级模式**。
5. 等待 USB 设备重新出现，点击 **选择引导设备并刷写**。引导设备标识为 `484D:0003`，名称可能不包含 Pulsar；保持只接入这一只目标鼠标。
6. 点击 **重新连接鼠标并验证**，选择重新出现的有线 Xlite v4，检查版本和配置。目标版本在界面显示为 `1.0.1.7`，诊断中的原始值为 `00.00.10.17`；本地未应用草稿会保留。

刷写期间不要拔线、断电、关闭或刷新页面。出错后不会自动重试刷写；请按弹窗提示检查设备模式，再选择重试或返回。刷新会丢失本次升级会话；若鼠标停留在引导模式，请使用官方升级器恢复。引导设备使用共享标识，不能仅凭 ID 确认型号或是否为刚才那只鼠标，必须只保留目标设备。

断电或中断恢复、其他固件/型号，以及升级后的 8K 无线重连尚未确认。刷写后非活动槽位的性能设置及非空宏的保留情况也未全面确认。文件哈希及技术证据见 [固件说明](docs/firmware.md) 和 [验收记录](docs/verification.md)。

## 哪些更改会即时生效

连接并读取设备后，性能设置在后台自动保存，无需点击 **应用到鼠标**：

| 设置 | 保存时机 |
| --- | --- |
| 当前 DPI 档位、档位增删、回报率、LOD、Motion Sync、角度捕捉、波纹控制、DPI 灯光效果 | 点击后自动保存 |
| DPI X/Y 数值 | 实际修改后，按 Enter 或离开输入框时写入 |
| DPI 档位颜色 | 完成颜色选择后自动保存 |
| 消抖时间、灯光亮度、呼吸速度 | 松开滑块或调节键后写入；仅聚焦不会保存 |
| 按键映射、电源、导入及默认值草稿 | 点击 **应用到鼠标** |
| 宏内容 | 点击上传；按键中的宏绑定仍需应用 |

保存期间仍可继续调整性能设置。每次操作只保存本次调整的设置，其他草稿保留。有未应用的 DPI 布局时，修改 DPI 数值、切换档位、选择档位颜色或增删档位，会一起保存当前可见的 DPI 档位布局；其他草稿仍需点击 **应用到鼠标**。

离线编辑、导入配置和重新连接不会自动写入旧草稿。设备配置发生外部变化或后台保存失败时，自动保存会暂停并显示错误；请重新读取实际设置后继续。

## 限制与风险

- 浏览器无法修改 Windows 指针速度、系统双击/滚轮速度、系统托盘和开机启动，也不能在页面失焦后全局录制键鼠。
- 暂不支持宏中的鼠标移动轨迹。长延迟的总时长会保留，但转换后的设备事件数量可能增加。
- 暂不支持实时无线信号显示及物理 DPI 按键状态的自动更新；请点击 **重新读取** 刷新状态。未知电量不代表 0% 或鼠标休眠。
- 1K / 8K 配对取消、超时及拔出后的恢复，全部回报率的稳定性与实际 USB 报告频率，全部按键的执行效果、宏在不同应用中的表现，以及破坏性重置，尚未全面确认。
- 8K 接收器切换为 **显示连接状态** 灯光模式后，读取完整配置可能超时。macOS 在 8000 Hz 下可能出现指针体感偏慢，原因尚未确认。回报率配置值不等于实际 USB 频率或延迟测量。
- 8K 无线兼容证据限于固件 `00.00.10.16`；升级至 `1.0.1.7` 后的 8K 无线重连尚未确认。
- 出厂恢复是实验性操作，会清除自定义设置并断开连接。执行前请导出配置及宏，之后重新连接检查实际状态。

原版 CSV 不保存循环方式；循环方式在设备按键绑定中设置。包含逗号键的宏请使用 JSON 导出。JSON 配置使用 Web 版格式，原版宏 CSV 请在宏编辑器中导入。

兼容范围和详细证据见 [验收记录](docs/verification.md)、[接收器配对说明](docs/receiver-pairing-evidence.md) 和 [文件格式说明](docs/native-files.md)。

## 界面语言

通过页面顶部的 **中文 / English** 切换语言。首次使用根据浏览器语言选择中文或英文，不支持时使用 English；之后记住你的选择。切换语言不会更改鼠标设置、配置或宏，配置与宏名称保留用户原文。
